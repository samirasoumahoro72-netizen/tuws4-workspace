## Brand & Style

This design system establishes an intelligent, high-clarity canvas for next-generation digital collaboration, workflow automation, and AI augmentation. Eschewing the conventional heavy, dark navy aesthetic of legacy enterprise software, the interface leverages the crisp, weightless clarity of sky blue and luminous air-tinted surfaces. The visual tone is fluid, forward-looking, and rigorously structured.

The style synthesizes modern corporate precision with lightweight glass-tinted clarity and soft ambient physics:
- **Atmospheric Clarity:** An airy, open canvas that reduces cognitive fatigue during prolonged operational cycles.
- **Precision Engineering:** Subtle structural gridlines, fine hairline borders, and intentional geometric proportions ensure high data density remains effortlessly legible.
- **Dynamic Energy:** Focused bursts of warm amber-orange act as precision beacons for high-priority user actions, pending AI interactions, and mission-critical states.

## Colors

The color palette is engineered around pure atmospheric light, balancing high-contrast utilitarian slates with lucid sky tones and tactical energetic accents:

- **Primary (`#0ea5e9` - Electric Sky):** The operational backbone, used for core navigation, interactive active states, selection perimeters, and key digital workspace anchors.
- **Secondary (`#38bdf8` - Luminous Azure):** Ambient accents, subtle indicators, hover states, contextual focus glow rings, and multi-tier interactive highlights.
- **Tertiary (`#f97316` - Radiant Pulse Orange):** High-priority call-to-actions, generative AI execution triggers, active system warnings, and critical badge statuses.
- **Neutral Palette (`#64748b` - Slate Matrix):** Built on cool architectural slates:
  - Deep Ink (`#0f172a`): High-contrast primary typographic content and authoritative structural headers.
  - Muted Charcoal (`#334155`): Secondary body copy, input text, and table data.
  - Border Slate (`#cbd5e1` & `#e2e8f0`): Crisp, low-contrast bounding boxes, dividers, and surface demarcations.
  - Sky Tint Foundation (`#f8fafc` & `#f0f7ff`): Background surfaces, container tiers, and workspace stage canvases tinted with delicate optical blue wavelengths.

## Typography

Plus Jakarta Sans delivers structural geometry with humanized terminals, providing clear, open letterforms that remain crisp across high-density AI dashboards, code windows, and analytics streams.

- **Numerics & Tabular Alignment:** Financial figures, prompt token metrics, and run counts utilize tabular figure settings (`font-feature-settings: 'tnum' on, 'cv05' on`) to ensure zero visual jitter during real-time data ingestion.
- **Hierarchy Enforcements:** Heavy weights (`700`, `800`) are reserved strictly for top-level orientation and contextual landmark headers. Operational UI relies heavily on `500` and `600` weights paired with tight letter spacing (`-0.01em` to `-0.025em`) to balance authority with geometric cleanliness.

## Layout & Spacing

A strictly governed 8px baseline rhythm coordinates all operational surfaces. The workspace employs a fluid grid underpinned by collapsible multi-pane spatial architecture:

- **Desktop (1280px+):** 12-column dynamic framework with `gutter-desktop` (24px) and adaptive perimeter margins. Modular side panels (navigation, agent inspector, live logs) sit on deterministic fixed tracks (64px collapsed, 280px standard, 380px inspector) while central document and data canvases flex continuously.
- **Tablet (768px - 1279px):** 8-column responsive layout with `gutter-desktop` (24px) and 32px safe outer padding. The tertiary inspector pane transitions to an overlay drawer.
- **Mobile (< 768px):** 4-column stacking system with `gutter-mobile` (16px) and 16px screen-edge margins. Primary navigation converts to a low-profile docked bottom dock bar with direct thumb reach zones.

## Elevation & Depth

Visual hierarchy abandons heavy, muddy drop shadows in favor of luminous depth, sky-tinted ambient diffusion, and hairline boundary separation:

- **Base Layer (Surface 0):** Pure atmospheric canvas (`#f0f7ff` to `#f8fafc`) with subtle macro gradients simulating soft northern light.
- **Card & Workspace Panels (Surface 1):** Solid crisp white (`#ffffff`) or frosted translucency (`rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(12px)`). Delineated by a hairline perimeter border (`1px solid #e0eefb`).
- **Floating Modals & Flyouts (Surface 2):** Elevated via ultra-diffused atmospheric blue shadows: `box-shadow: 0 12px 32px -4px rgba(14, 165, 233, 0.08), 0 4px 12px -2px rgba(15, 23, 42, 0.04)`.
- **Active Focus & Agent Glow:** Interactive inputs and processing elements generate a twin halo ring: `0 0 0 3px rgba(14, 165, 233, 0.18)`.

## Shapes

The geometry balances technical capability with tactile approachability:
- Standard UI nodes (inputs, action tiles, contextual cards) incorporate a calibrated `0.5rem` (8px) radius.
- Enclosing workspace panels, dashboard widgets, and modal dialogues expand to `1rem` (16px) radius to maintain softness at larger visual volumes.
- Micro-elements such as AI prompt chips, status badges, and active session pills scale smoothly up to fully circular/pill caps (`9999px`).

## Components

### Buttons
- **Primary Action:** Solid vibrant Sky Blue background (`#0ea5e9`), pure white label (`#ffffff`), subtle inset light highlight on top border. Hover shifts to `#0284c7` with micro-lift transition (`translateY(-1px)`).
- **Secondary / Surface:** Crisp white background, `1px solid #cbd5e1` outline, Slate 800 typography (`#1e293b`). Hover introduces `#f0f7ff` tint and `#0ea5e9` border transition.
- **High-Impact AI / Critical Trigger:** Vibrant Orange fill (`#f97316`) with white text. Reserved for primary conversion, generative runs, deployment executions, and urgent workflow pushes.

### Input Fields & Search Bars
- Background set to `#ffffff`, bound by hairline border `#cbd5e1`. 
- Placeholder styled in `#94a3b8`.
- Focus state instantly replaces slate borders with Sky Blue (`#0ea5e9`) accented by an atmospheric glow (`0 0 0 3px rgba(14, 165, 233, 0.15)`).

### Chips & Badges
- **Status Indicators:** Pill geometry (`rounded-full`) utilizing a tinted background with deep paired text.
  - Active / Connected: `#e0f2fe` background with `#0369a1` text and an animated `#0ea5e9` pulse dot.
  - Processing / AI Thinking: `#ffedd5` background with `#c2410c` text and `#f97316` indicator dot.
  - Neutral / Offline: `#f1f5f9` background with `#475569` text.

### Cards & Container Panels
- White solid foundation with `#e2e8f0` outer rim.
- Hover states on interactive task cards transition border to `#bae6fd` while raising the atmospheric blue drop shadow.

### Checkboxes & Radio Controls
- Square with 4px radius for checkboxes; full round for radios.
- Unchecked: `#ffffff` fill, `#94a3b8` stroke. Checked: `#0ea5e9` fill with crisp white vector check icon or inner disc.

### Specialized AI Workspace Elements
- **Prompt Execution Bar:** Floating pill-shaped dock centered in workspace view with glassmorphic backdrop blur, internal prompt input, quick-action chips, and an anchored circular orange execution trigger button.
- **Streaming Response Card:** Left-anchored vertical border track in Sky Blue (`#38bdf8`) displaying real-time markdown typography and mono-spaced code execution blocks with copy actions.
